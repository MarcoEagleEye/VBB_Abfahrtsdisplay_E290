VBB Abfahrtsdisplay Berlin

Heltec Vision Master E290 · bis zu 4 Bahnhöfe · VBB-Livedaten

Bitte Chrome, Edge oder einen Browser mit WebSerial-Unterstützung am PC verwenden.

Der Installer muss über HTTPS geöffnet werden.

Erste Einrichtung

  1. E290 per USB-C anschließen und Installieren wählen.
  2. Bei der Erstinstallation Erase device aktivieren.
  3. Danach Connect to Wi-Fi und dein 2,4-GHz-WLAN eintragen.
  4. Visit device öffnet das Einstellungsportal.
  5. Bis zu vier Bahnhöfe suchen, optional Ziele auf Richtung A/B verteilen und speichern.

BOOT kurz schaltet durch alle Ansichten; BOOT 2 s springt direkt zum nächsten Bahnhof.

Update

Beim Update Erase device nicht aktivieren. Dadurch bleiben WLAN, Bahnhöfe und A/B-Zuordnungen im NVS erhalten.

Alternativ kann firmware.bin im Einstellungsportal hochgeladen werden.

Von der originalen MVG-Firmware wechseln

Ist auf dem E290 noch das originale MVG Abfahrtsdisplay installiert, diesen Migrationsknopf verwenden. Er benutzt dieselbe VBB-Firmware, meldet sich für genau diesen einen Wechsel aber mit dem alten Firmware-Namen, damit ESP Web Tools ein Update ohne Löschen anbietet.

Bitte einen Browser mit WebSerial-Unterstützung am PC verwenden.

Erase device ausgeschaltet lassen. WLAN/QR/Filter bleiben erhalten. Die alte Münchner Haltestelle wird absichtlich verworfen und danach im VBB-Portal neu gewählt.

Hinweis

Die Abfahrtsdaten kommen von der öffentlichen VBB-Transport-REST-Schnittstelle. Dieses Projekt ist kein offizielles Angebot von VBB oder BVG.
